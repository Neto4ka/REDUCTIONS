Continuous stream architecture. The file is connected via <audio> + URL.createObjectURL → createMediaElementSource(): the browser itself streams all 50 minutes from disk in chunks, and the entire file never resides in RAM on a phone. The ring buffer (the last ~4 s of live signal) serves the granulator, clouds, reverses, and loops. The effects live in two parallel buses that crossfade at every pattern boundary — there are no seams physically.
Method. Levels: d — documented technique, r — reconstruction, i — free interpretation. Transformation taxonomy — Trevor Wishart, "Audible Design" (1994). Blocks 015 (Brody) and 054 (Kamin) share an echo motif: friends who died in the same car crash in 2010. If the file is longer than 50:00, the composer list loops.
